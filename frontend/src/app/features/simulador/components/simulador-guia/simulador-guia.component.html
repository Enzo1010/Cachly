Onde está o byte dentro do bloco?

A memória principal envia blocos completos de dados (ex: 16 ou 32 bytes). O Offset indica a posição exata do byte desejado pela CPU dentro desse bloco carregado.

Exemplo: Se o bloco tem 16 Bytes, temos log₂(16) = 4 bits de offset (permite endereçar os bytes de 0 a 15).
ÍNDICE (Index / Set) log₂(Total de Conjuntos)

Em qual conjunto/linha procurar?

Funciona como o "endereço da prateleira". O Índice aponta diretamente para qual linha (no mapeamento direto) ou conjunto de vias a cache deve consultar.

Exemplo: Se a cache tem 4 conjuntos, temos log₂(4) = 2 bits de índice. No mapeamento totalmente associativo, o índice é 0 bits.
TAG (Rótulo) Total Bits − (Índice + Offset)

O dado que está ali é o correto?

Como vários blocos da RAM compartilham a mesma linha da cache, o Tag armazena os bits restantes mais significativos. O comparador de hardware valida se o Tag guardado na linha é idêntico ao solicitado pela CPU.

Exemplo: Em um endereço de 8 bits com 2 bits de índice e 4 de offset, sobram 8 − (2 + 4) = 2 bits para a Tag.

Como os blocos são distribuídos na Cache?

O tipo de mapeamento define a liberdade que um bloco da memória principal tem para ser alocado nas linhas da memória cache:

1 Via por Conjunto

Mapeamento Direto

Cada bloco da RAM mapeia para uma única linha específica da cache calculada por Linha = Bloco mod (Total de Linhas).

  • Vantagem: Circuito simples, menor tempo de busca e baixo consumo.
  • Desvantagem: Alto número de faltas por conflito se dois endereços frequentes disputarem a mesma linha.
N Vias por Conjunto

Associativo por Conjunto (Set-Associative)

A cache é dividida em conjuntos, e cada conjunto contém N linhas (vias). O bloco é direcionado ao conjunto pelo Índice, mas pode ocupar qualquer via livre desse conjunto.

  • Vantagem: Reduz drasticamente colisões com excelente relação custo-benefício (padrão em processadores modernos).
  • Trade-off: Requer política de substituição (LRU/FIFO) para decidir qual via desocupar.
1 Único Conjunto

Totalmente Associativo

Um bloco pode ser posicionado em qualquer linha livre da memória cache. Não há bits de índice no endereço.

  • Vantagem: Elimina 100% das faltas por conflito de mapeamento.
  • Desvantagem: Requer comparadores de Tag em todas as linhas em paralelo, encarecendo o hardware.

O que acontece quando a Cache enche?

Quando todas as linhas de um conjunto estão ocupadas e ocorre uma falta (*miss*), o processador deve escolher uma linha para ser descartada ou sobrescrita:

LRU — Least Recently Used

Menos Recentemente Utilizado

Descarta o bloco que ficou o maior período de tempo sem nenhum acesso pela CPU.

Princípio Físico: Baseia-se na Localidade Temporal (dados acessados recentemente têm maior probabilidade de serem acessados novamente). É a política mais eficiente para a maioria dos programas.

FIFO — First In, First Out

Primeiro a Entrar, Primeiro a Sair

Descarta o bloco que foi carregado na cache há mais tempo, funcionando como uma fila de espera.

Princípio Físico: Mais simples de implementar em hardware (usa um contador circular), porém pode cometer o erro de descartar um bloco muito utilizado apenas por ele ter entrado cedo.

Entendendo Acertos e os 3 Tipos de Faltas

O desempenho de um sistema computacional depende da taxa de acertos da cache. Entenda a anatomia dos resultados:

CACHE HIT (Acerto)

O bloco solicitado pela CPU já está presente em uma linha da cache, o Bit de Validade é 1 e o Tag confere. O dado é entregue em ~1 a 3 ciclos de clock.

Miss Compulsório (Cold Miss)

Ocorre no primeiro acesso do programa àquele bloco de memória. É inevitável, pois a cache é inicializada vazia (todas as linhas inválidas).

Miss de Conflito

Ocorre quando múltiplos blocos da RAM são mapeados para o mesmo conjunto/linha e disputam espaço, mesmo que ainda existam linhas vazias em outros conjuntos.

Miss de Capacidade

Ocorre quando o volume total de dados ativos que o programa utiliza é maior do que o tamanho físico total da memória cache.
